# Worked example

A complete, runnable demonstration of the autograder on a small invented 10-mark "bakery" exam. It has two parts:

- **`example_autograder/`** — the autograder for the example exam: the framework plus a fully filled-in exam kit. Its [README](example_autograder/README.md) is a guided tour of every artefact.
- **`example_submission/`** — a sample student submission to feed through it: a perfect-scoring `bakery/` upload. See its [README](example_submission/README.md).

Together they let you run the whole pipeline end to end and watch the marking and fallback behaviour in action. Start with the [autograder README](example_autograder/README.md), whose "Run it yourself" section drives the submission through the container the way Gradescope does.
